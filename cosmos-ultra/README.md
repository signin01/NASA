# COSMOS ULTRA

Deep Space Intelligence Platform built with Vite, modular JavaScript, NASA/public space APIs, Leaflet, Chart.js, Three.js, and satellite.js.

## Run Locally

npm install
npm run dev

Open http://127.0.0.1:5173

## Build

npm run build
npm run preview

## Notes

Some live APIs may fail because of rate limits, CORS, temporary outages, or network restrictions. The app includes cache and fallback behavior where practical.
